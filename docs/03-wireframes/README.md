# بشقاب‌یار — وایرفریمها

## هدف

این پوشه حاوی وایرفریمهای خاکستری (سطح Sketch → Wireframe) برای ۶ صفحهٔ موبایل و ۵ صفحهٔ وب است. هدف، تثبیت **جایگاه عناصر، ترتیب RTL و مسیرهای کلیک** پیش از نوشتن کد رابط کاربری است. رنگها و فونتها در [`../02-design-system.md`](../02-design-system.md) تعریف شدهاند؛ در وایرفریمها تنها از خاکستری برای جلوگیری از حواسپرتی استفاده میشود.

## نحوهٔ باز کردن

هر دو فایل HTML کاملاً مستقلاند و هیچ وابستگی خارجی (CSS، JS، فونت، تصویر) ندارند. کافی است آنها را در مرورگر باز کنید:

- `mobile-wireframes.html` — ۶ قاب 375×812 پیکسل
- `web-wireframes.html` — ۵ صفحهٔ دسکتاپ راستچین

## فهرست صفحات

### موبایل (اندروید، ۳۷۵dp)

| شماره | صفحه | مسیر / ورودی | اقدام اصلی | خروجی کلیدی |
|---|---|---|---|---|
| M1 | ورود | `/login` | دکمهٔ «ورود» | نشانهٔ JWT و رفتن به خانه |
| M2 | خانه / خلاصهٔ روز | Bottom nav → خانه | FAB «ثبت وعده» | کالری مصرفشده و لیست وعدهها |
| M3 | ثبت وعده | FAB یا نوار پایین | «ثبت وعده» | محاسبهٔ قطعی سهم و ذخیره |
| M4 | پیشنهادها | بعد از ثبت / دکمهٔ پیشنهاد | «جایگزین کن» | ۲–۳ جایگزین بر اساس هدف + قیمت |
| M5 | گزارش | Bottom nav → گزارش | تب «هفته» (Pro) | نمودار روزانه و هشدار تخمینی |
| M6 | نمایه / ارتقا | Bottom nav → نمایه | «ارتقا به Pro» | هدف، بودجه، وضعیت طرح |

### وب (واکنشگرا، راستچین)

| شماره | صفحه | مسیر پیشنهادی | اقدام اصلی | نکتهٔ چیدمان |
|---|---|---|---|---|
| W1 | فرود | `/` | CTA «همین الآن امتحان کن» | الگوی Z، فقط یک رنگ تأکیدی |
| W2 | داشبورد | `/app` | دکمهٔ «ثبت وعده» | سایدبار راست، سه کارت خلاصه |
| W3 | ثبت وعده | `/app/meals/new` | «ذخیره» | breadcrumb، segment سهم |
| W4 | گزارشها | `/app/reports` | «ارتقا» در طرح آزاد | جدول + هشدار تخمینی |
| W5 | پنل مدیریت | `/admin` | فیلتر رویدادها | سه آیتم سایدبار، جدول رویدادها |

## جریانهای اصلی

### جریان A — ثبت اولین وعده (حداقل مسیر)

```text
M1 ورود → M2 خانه → M3 ثبت وعده (انتخاب غذا + سهم) → M2 خانه (کارت بهروز شد)
API: POST /api/auth/login → GET /api/me → GET /api/foods → POST /api/meals → GET /api/reports/daily
```

### جریان B — انتخاب جایگزین بر اساس هدف و بودجه

```text
M3 ثبت وعده → M4 پیشنهادها → انتخاب جایگزین → M2 خانه
API: POST /api/meals → GET /api/recommendations/:mealId → POST /api/meals (جایگزین)
```

### جریان C — خواندن گزارش و ارتقا

```text
M2 خانه → M5 گزارش → مشاهدهٔ قفل «هفته» → M6 نمایه → ارتقا (شبیهسازی)
API: GET /api/reports/daily → GET /api/reports/weekly → 403 PLAN_LIMIT → POST /api/upgrade (mock)
```

### جریان D — بازدید وب و ثبت اولین وعده

```text
W1 فرود → ثبتنام → W2 داشبورد → W3 ثبت وعده → W4 گزارش
```

### جریان E — بررسی مدیریتی توسط ادمین

```text
W5 پنل → نمای کلی → رویدادها → فیلتر `meal_logged`
API: GET /api/admin/overview → GET /api/admin/events?event=meal_logged
```

## قرارداد وایرفریم

- تمام جعبهها خاکستریاند؛ متن توضیحی داخل جعبهها فارسی است.
- خطچین (`dashed`) یعنی محتوای پویا که از API میآید.
- مستطیل تیرهتر یعنی دکمهٔ اصلی؛ در هر صفحه حداکثر یکی.
- فلشها و chevronها در RTL آینهاند (بازگشت در بالا-راست، chevron به سمت چپ).
- نوار پایین موبایل همیشه چهار آیتم دارد: خانه، ثبت وعده، گزارش، نمایه (از راست).
- ابعاد لمسی و فاصلهها مطابق [`../02-design-system.md`](../02-design-system.md)اند (≥48dp، ضریب 8).
- شمارهٔ صفحه در بالای هر قاب و نام endpoint مربوطه در زیرنویس ذکر شدهاست.
